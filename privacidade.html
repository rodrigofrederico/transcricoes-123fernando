Política de Privacidade

Última atualização: 18 de setembro de 2026

O aplicativo Transcricoes 123Fernando utiliza a YouTube Data API para acessar dados do YouTube mediante autorização explícita do usuário através do Google OAuth.

Dados acessados

O aplicativo pode acessar informações do canal, vídeos e faixas de legendas disponibilizadas pela YouTube Data API.

Finalidade

Os dados são utilizados para consultar vídeos e obter legendas e transcrições dos vídeos do canal 123Fernando.

Armazenamento

As credenciais de autorização OAuth utilizadas pela ferramenta são armazenadas localmente no computador utilizado para executar a aplicação e não são disponibilizadas publicamente.

As transcrições obtidas podem ser armazenadas localmente para utilização interna pelos usuários autorizados.

Compartilhamento de dados

Os dados obtidos através da YouTube Data API não são vendidos nem disponibilizados a terceiros pelo aplicativo.

Revogação do acesso

O usuário pode revogar a autorização concedida ao aplicativo a qualquer momento através das configurações de segurança de sua Conta Google.
